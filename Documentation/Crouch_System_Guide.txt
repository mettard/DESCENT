========================================================
ЯК ПРАЦЮЄ ПРИСІДАННЯ
========================================================

ЗВИЧАЙНИЙ СТАН:
- Висота камери: 1.5 studs
- Швидкість: 16 studs/сек
- HipHeight: 0 (стандарт)

ПРИСІДАННЯ (Ctrl/C):
- Висота камери: 0.8 studs (плавно опускається)
- Швидкість: 8 studs/сек (вдвічі повільніше)
- HipHeight: -0.5 (ближче до підлоги)
- Тряска камери: 50% від звичайної

ПЕРЕХІД:
- Плавний (CROUCH_SPEED = 8)
- ~0.1 секунди на повний перехід

========================================================

========================================================
ВИКОРИСТАННЯ ДЛЯ ВЕНТИЛЯЦІЇ
========================================================

КОНЦЕПЦІЯ:
1. Гравець підходить до вентиляції
2. Бачить промпт "Присядь (Ctrl)"
3. Присідає
4. Промпт змінюється на "Залізти (E)"
5. Натискає E → телепортується на вихід

КОД (VentilationEntry_Example.lua):
- Перевіряє _G.IsCrouching()
- Якщо true → дозволяє залізти
- Якщо false → показує підказку

========================================================
СТВОРЕННЯ ВЕНТИЛЯЦІЇ В КІМНАТІ
========================================================

КРОК 1: Створити модель

Ventilation (Model)
  ├─ Entrance (Part) - вхід
  ├─ Exit (Part) - вихід
  ├─ Tunnel (папка з Parts) - візуальна труба
  └─ VentilationEntry (Script)

КРОК 2: Налаштувати Entrance

Part властивості:
- Size: 2, 1, 2 (низький, щоб треба було присісти)
- Position: біля підлоги (~1 stud висота)
- Color: темно-сірий
- Material: Metal
- Transparency: 0.3
- CanCollide: false

КРОК 3: Налаштувати Exit

Part властивості:
- Size: 2, 1, 2
- Position: в іншій кімнаті або за стіною
- Transparency: 1 (невидимий)
- CanCollide: false

КРОК 4: Додати візуальну трубу (опціонально)

Створити кілька Parts що формують тунель:
- Material: Metal
- Color: темний
- Розмір: 2×2×4 (залежить від довжини)
- З'єднати між Entrance і Exit

КРОК 5: Додати скрипт

VentilationEntry.lua → всередину моделі Ventilation

ПРИКЛАДИ ВИКОРИСТАННЯ

ПРИКЛАД 1: Вентиляція в серверній кімнаті

RoomServer/

      ├─ Entrance (біля входу)
      ├─ Exit (за серверними стійками)

Призначення: Скорочений шлях, але ризикований
(можна застрягти якщо монстр чекає на виході)

ПРИКЛАД 3: Секретна кімната

RoomDark/
  └─ Ventilation → SecretRoom (з лутом)

Призначення: Винагорода за дослідження

========================================================
ТЕСТУВАННЯ
========================================================

ТЕСТ 1: Базове присідання
1. Запустити гру
2. Натиснути Ctrl або C
3. Камера опускається
4. Швидкість зменшується
5. Output: "🔽 Присів"

ТЕСТ 2: Плавний перехід
1. Присісти
2. Камера плавно опускається ~0.1 секунди
3. Не має бути різких стрибків

ТЕСТ 3: Ходьба при присіданні
1. Присісти
2. Рухатись WASD
3. Швидкість має бути вдвічі менша
4. Тряска камери слабша

ТЕСТ 4: Вентиляція БЕЗ присідання
1. Підійти до вентиляції стоячи
2. Натиснути E
3. Підказка: "Присядь щоб залізти!"
4. Телепортація НЕ відбулась

ТЕСТ 5: Вентиляція З присіданням
1. Підійти до вентиляції
2. Присісти (Ctrl)
3. Промпт змінюється: "Залізти ✅"
4. Натиснути E
5. Телепортація на Exit
6. Звук металевого повзання

========================================================
ІНТЕГРАЦІЯ З МОНСТРАМИ
========================================================

ІДЕЯ: Монстр НЕ БАЧИТЬ гравця який присів у вентиляції

В WandererAI додати перевірку:

local function FindVisiblePlayer()
	-- ... існуючий код ...
	
	-- 🔽 НОВИЙ КОД: Ігноруємо гравців у вентиляції
	if character:GetAttribute("InVentilation") then
		continue -- Пропускаємо цього гравця
	end
	
	-- ... решта коду ...
end

І в VentilationEntry при заході:
player.Character:SetAttribute("InVentilation", true)

При виході:
player.Character:SetAttribute("InVentilation", false)
